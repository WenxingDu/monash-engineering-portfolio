This is not a standalone research project, and it is not a carefully engineered final system.

It is a record of:
- testing different model and training choices,
- observing training behaviour,
- and learning where performance gains stop being reliable.

The emphasis is on understanding model behaviour, not on claiming optimal performance.


## Organisation

The work is split into several tasks, each implemented as a separate notebook:

- **Task 1**  
  Initial setup and baseline training.  
  Used mainly to understand data flow, loss behaviour, and early limitations.

- **Task 2**  
  First round of changes motivated by issues observed in Task 1.  
  Some improvements were visible, others were marginal.

- **Task 3**  
  Further adjustments to optimisation and training strategy.  
  This stage highlighted how sensitive the model was to hyperparameter choices.

- **Task 4**  
  Longer or more careful training based on previous observations, including checkpoint tracking.

- **Task 5**  
  Final consolidation.  
  The focus here was less on pushing metrics further, and more on checking whether improvements were consistent.

The tasks are meant to be read roughly in order. Later notebooks assume familiarity with earlier ones.
