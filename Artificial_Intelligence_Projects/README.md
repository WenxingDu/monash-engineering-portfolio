# Artificial Intelligence Projects

This folder contains a small collection of projects completed during my engineering studies.

They are not meant to be read as isolated showcases, but as work done at different levels: 
from experimenting with learning models, to planning and control, and finally to running a full robotic system under uncertainty.

A brief overview is given here.  
More detailed explanations, design decisions, and limitations are documented in the README files of each individual project.


### Autonomous Vehicle Systems
Path planning, trajectory generation, and receding horizon control for autonomous vehicles.

Most of the work here is about how planning, feasibility, and control interact in practice, rather than treating them as separate problems.


### Deep Learning
A set of notebook-based experiments exploring training behaviour, optimisation choices, and generalisation limits.

This section keeps the trial-and-error process visible instead of presenting a single polished model.


### Intelligent Robotics
An integrated robotics project combining SLAM, mapping, and navigation on a real robot.

The difficulty comes from both algorithmic implementation and system behaviour under noise, drift, and partial failure during long runs.



Overall, these projects reflect an increasing focus on system behaviour and robustness, rather than isolated performance metrics.
